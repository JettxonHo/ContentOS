**Status:** Current Truth

`M2-QUAL-001` adds milestone evidence to the existing Vitest integration and Playwright browser harnesses. It does not make an M2 acceptance decision; `M2-GOV-005` runs the recorded commands from the accepted `main` commit and creates the immutable Acceptance Record.

## Reproducible command set

```text
corepack pnpm check
corepack pnpm repository:check
corepack pnpm test:integration
corepack pnpm test:integration:concurrent
corepack pnpm test:browser
```

The two smoke commands own an isolated `contentos-smoke-*` project, tmpfs data, temporary credentials, and bounded cleanup. They never touch `contentos-local` volumes or unrelated containers.

The new backend success path is real authenticated API Command → owned Worker Outbox dispatch → fixed BullMQ Job → committed Fetcher classes with the existing public-address test transport provider → Snapshot/Result/Source → public Version/Approval APIs → owner-scoped approved-input projection and Workflow REST reads. Its controlled connector maps a representative public DNS result to a test-owned loopback fixture only; it does not change production address policy or make a public-network request.

The process SSRF test removes inherited uppercase/lowercase proxy variables, `NODE_USE_ENV_PROXY`, any `NODE_OPTIONS` `--use-env-proxy`, and `DATABASE_URL` from the Fetcher child environment. It uses the existing ephemeral smoke S3 credential pair under Fetcher-prefixed names; it does not claim distinct production S3 principals.
